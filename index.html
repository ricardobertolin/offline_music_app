Quality target

Nothing here touches your files until you run Normalize quality on the Quality tab or from a record. It only describes what a re-encoded file should look like, and which files therefore count as outliers.

Opus is a modern lossy codec — at any given size it sounds better than MP3 or AAC, so it is the right choice for shrinking a library of already-lossy files. It throws away data, so re-encoding a FLAC to Opus loses quality permanently unless you keep the original below. Pick WAV to re-encode without loss (much larger files).

Artwork

Repair re-reads the cover embedded in each audio file and reassigns it — use it if a track is showing another record's cover.

Backup

The library lives in this browser's storage, which a cleared profile, a reinstall or the browser reclaiming space will take with it. A backup is an ordinary .zip — your audio, your covers and a manifest of every measurement — written straight to a file you choose. Nothing is uploaded.

—

Measurements only leaves the audio out, so it is small and quick. It is still worth taking: restore it, re-import the same files, and every track reattaches by content hash with its loudness, quality, artwork and tag edits intact.

Linked folders

A linked folder is read where it sits, so the app never keeps a second copy of your music. Only the measurements are stored here, which is a few MB. Files you add to the folder show up on the next scan.

Browsers do not always keep folder permission across a reload — if a linked track will not play, reconnect it here.

Storage

The JSON export is a readable report, not a backup — use Back up the library above for something you can restore.

About

Loudness follows ITU-R BS.1770-4 / EBU R128: K-weighted gated integrated loudness (LUFS), loudness range (LRA) and 4× oversampled true peak. Album gain is recomputed from the gated block histogram of every track on the record, not averaged. Quality detection measures effective bandwidth (spectral cutoff), clipping, crest factor and bitrate. Everything runs locally; the service worker makes the app itself work offline.
